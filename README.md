# tech-demos

One Bun app per tech demo, under `apps/<kebab-slug>/`. Each app is self-contained and has its own `PLAN.md`.

```bash
cd apps/<slug> && bun install && bun run dev
```

Each demo PR includes at least one screenshot and one video of the running app.
